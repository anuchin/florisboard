# FlorisBoard

Free, open-source Android keyboard (Kotlin + Jetpack Compose). Multi-module Gradle build, targets Android 8+ (minSdk 26, compileSdk/targetSdk 36). AGP 9.0.0, Kotlin 2.3.20, JDK 17.

## Build & verify

- Manual build (matches CI): `./gradlew clean && ./gradlew assembleDebug --stacktrace`
- Build types: `debug` (appId suffix `.debug`, installs side-by-side with stable), `beta` (appId suffix `.beta`), `release`, `benchmark` (appId suffix `.bench`).
- Library modules: `:lib:android`, `:lib:color`, `:lib:compose`, `:lib:kotlin`, `:lib:native`, `:lib:snygg`. App depends on all of them.
- App entrypoint modules under `app/`: the IME service `dev.patrickgold.florisboard.FlorisImeService` and the app class `dev.patrickgold.florisboard.FlorisApplication` (see `app/src/main/AndroidManifest.xml`).
- Lint baseline: `app/lint.xml`. Run `./gradlew :app:lintDebug`.
- System requirements: Linux or WSL2, 16GB RAM, Android Studio (or IntelliJ + Android/Compose plugins), JDK 17, CMake 3.22+, Clang 15+, Rust toolchain. IntelliJ users must enable "Future AGP Versions" or AGP 9.0.0 will not sync (see CONTRIBUTING.md).

## Test

- JUnit 5 platform (`useJUnitPlatform`). Frameworks: Kotest 6, Turbine, kotlinx-coroutines-test.
- Run all unit tests: `./gradlew test`.
- Run a single module: `./gradlew :app:testDebugUnitTest` (or `:lib:snygg:testDebugUnitTest`, etc.).
- Run a single test class/method: `./gradlew :app:testDebugUnitTest --tests "dev.patrickgold.florisboard.SomeTest" --tests "*.<methodName>"`.
- Coverage via Kover (`./gradlew koverXmlReport` / `koverHtmlReport`).
- Instrumentation tests live in `app/src/androidTest` and `app/src/test`; use Espresso/ext-junit for androidTest.

## Repository layout

- `app/` — application module, namespace `dev.patrickgold.florisboard`.
- `lib/*` — internal libraries (UI, theming/Snygg, color, native bridge, kotlin utils, android base).
- `libnative/dummy/` — a placeholder native module (not included in `settings.gradle.kts`); real native code lives in `lib/native/src/main/rust/` and is built via CMake target `fl_native`.
- `benchmark/` — currently excluded from `settings.gradle.kts` (commented out).
- `utils/` — Python helper scripts (e.g. `generate_spellcheck_config.py`, `convert_fcitx5_sqlite.py`); require Python 3.10+ and an attached ADB device.
- `fastlane/` — release/Play Store metadata and screenshot generation.

## Critical constraints (read before editing)

- **AI policy (`AI_POLICY.md`)** is strict and is part of the contribution agreement. Autonomous AI agent contributions are prohibited, and any code, comments, commit messages, or PR descriptions must be human-authored. Machine translation and dedicated narrow-AI spellcheckers are the only AI exceptions (must be disclosed in the PR's first comment). The PR template requires the contributor to confirm they read both `CONTRIBUTING.md` and `AI_POLICY.md`.
- **Translations are Crowdin-only.** Never add or edit files matching `app/src/main/res/values-*/strings.xml` — the `validate-strings-no-translations.yml` workflow will fail the PR. The base `app/src/main/res/values/strings.xml` is the source of truth that Crowdin syncs against. `app/lint.xml` downgrades `ExtraTranslation` to a warning for the same reason.

## Generated / owned artifacts (do not hand-edit)

- `app/schemas/**/*.json` — Room database schemas, written by KSP at build time and **checked in**. Configure via the `room.schemaLocation` / `room.incremental` / `room.expandProjection` KSP args in `app/build.gradle.kts`.
- `lib/snygg/schemas/stylesheet.schema.json` — generated by the `generateJsonSchema` task, which is auto-`finalizedBy` `compileDebugKotlin` in `lib/snygg/build.gradle.kts`. Run `./gradlew :lib:snygg:generateJsonSchema` to regenerate explicitly.
- `app/src/main/res/xml/spellchecker.xml` — generated by `utils/generate_spellcheck_config.py` from a device's `no_backup/devtools/system_locales.tsv` (produced via the in-app devtools "save system locales" action).
- `app/src/main/config/` — AboutLibraries plugin config consumed by the `aboutLibraries` block in `app/build.gradle.kts`.
- `lib/native/src/main/rust/target/` — wiped by the `clean` task (see `lib/native/build.gradle.kts`).

## CI (`.github/workflows/`)

- `android.yml` — runs on push to `main` and `feature/*`, and on PRs to `main`. Builds with JDK 17 + CMake/Ninja, then `./gradlew assembleDebug --stacktrace`. Uploads `app/build/outputs/apk/debug/*.apk` as the `florisboard-debug-apk` artifact. Many doc-only paths are `paths-ignore`d. Submodules are checked out recursively.
- `validate-strings-no-translations.yml` — fails any PR that touches `app/src/main/res/values-*/strings.xml` (skips the `florisboard-bot` bot).
- `crowdin-upload.yml` — managed by the bot; do not invoke manually.

## Style & conventions

- Kotlin official code style (`kotlin.code.style=official` in `gradle.properties`); star imports at 99 (`ij_kotlin_name_count_to_use_star_import = 99` in `.editorconfig`).
- 4-space indent, LF, UTF-8, max 120 cols (`.editorconfig`); 2-space indent for `*.json`, `*.yml`, `*.sh`, `*.har`.
- `gradle.properties`: `org.gradle.parallel=true`, `org.gradle.warning.mode=all`, Xmx 4G. Treat Gradle warnings as errors to fix, not noise.
- Build versions and version code are centralized in `gradle.properties` (`projectMinSdk`, `projectTargetSdk`, `projectCompileSdk`, `projectVersionCode`, `projectVersionName`).
- JVM target 11 for all modules; AGP `nonFinalResIds` and `nonTransitiveRClass` are enabled — each module has its own `R` class.
- App `versionName` is split at `-`: anything after the dash becomes a `versionNameSuffix` for the `beta`/`release` build types. Debug adds `-debug+<git short hash>`.
